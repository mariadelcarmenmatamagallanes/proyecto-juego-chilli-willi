**Equipo:** Creatividad Digital + IA  
**Semestre:** 2026

---

## 📖 Descripción del Proyecto

**Chilli Willi** es un videojuego 3D desarrollado en el navegador web utilizando Three.js. El jugador controla a un personaje en un entorno ártico donde debe recolectar objetos, evitar obstáculos de hielo y completar desafíos para avanzar.

### Mecánicas principales:
- Personaje principal: **Chilli Willi**
- Escenario: entorno de hielo con iglú, plataformas y obstáculos
- Objetivo: recolectar elementos y completar el nivel
- Condición de victoria: llegar al pergamino final
- Condición de derrota: caer al vacío o que el hielo se rompa
